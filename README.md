# Apple Store India — Responsive E-Commerce Storefront Showcase

> **Live Website:** [https://apple-store-in.pages.dev/in/store](https://apple-store-in.pages.dev/in/store)

A high-fidelity static frontend showcase of the **Apple Store (India)** e-commerce experience, featuring localized product hubs, responsive merchandising grids, typography, and interactive hardware galleries.

## Included Storefront Sections
- **Store Home (`/in/store`):** Full Indian Rupee merchandising grid, carrier/financing cards, and specialist help panels.
- **Product Category Hubs:** Dedicated static builds for `Mac`, `iPhone`, `iPad`, `Apple Watch`, `AirPods`, `HomePod / TV`, `Vision Pro`, and `Accessories`.
- **Self-Contained Web Fonts & Media:** All `SF Pro Display`, `SF Pro Text`, and product assets bundled for reliable edge delivery without cross-origin failures or anti-bot stalls.

## Tech Stack
- Static HTML5, Modular CSS & Production JavaScript Bundles
- Self-hosted Typography (`.woff2`) & Responsive Media Pipeline
- Deployed globally on **Cloudflare Pages**

## Local Preview
Serve this folder with any static HTTP server and visit `/in/store`:
```bash
npx serve .
```
